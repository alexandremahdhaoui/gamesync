# GameSync

GameSync puts every installed Xbox and Game Pass PC game into your Steam library. One click. Full cover art. Full background art. A logo. A working icon. No manual setup.

## The problem

Xbox app games do not show up in Steam. You must add each one by hand. You must find the exe file. You must set the start folder. You must find an icon. You must repeat this for every single game. Most people skip this step. Their Xbox games stay stuck outside their real game library.

## Why this matters

Two separate game libraries cost you time and focus. You check two apps to see what you own. You check two apps to see what your friends play. You lose Steam Overlay and Steam friends list inside your Xbox games. GameSync removes this split. Every game lives in one place.

## What GameSync gives you

- Every real Xbox app game added to Steam automatically
- Cover art picked for you
- Background art picked for you
- A logo picked for you
- A working shortcut icon picked for you
- A review screen before anything changes
- A rename option for each game
- Safe re-import. Running it again never creates duplicates

## How it works

GameSync scans your Xbox games folder. It reads the game files already on your machine. It never contacts the internet. It never downloads art from any website. It writes your choices straight into Steam's own config files.

## Requirements

- Windows
- Steam installed
- Xbox app games already installed
- Steam closed during import

## Get started

1. Download `GameSync.exe`
2. Run it
3. Point it at your Xbox games folder and your Steam folder
4. Click Scan
5. Review the picks
6. Click Import
7. Open Steam. Your games are there
